# memory/decisions/

Architecture Decision Records — one file per non-obvious decision.

## File name
`NNN-<short-slug>.md` — zero-padded number, kebab-case slug.

## Template
```markdown
# ADR-NNN — <Title>

- **Status**: Proposed | Accepted | Superseded
- **Date**: YYYY-MM-DD
- **Decision by**: <role>

## Context
Why are we deciding this?

## Decision
What did we choose?

## Consequences
Good, bad, and the trade-off we accepted.

## Reference
Links to related ADRs or files.
```
