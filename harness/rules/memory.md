# Rule — Memory (Second Brain)

- **Read first, every session**: `memory/MEMORY.md` + relevant ADRs.
- **Write an ADR** (`memory/decisions/NNN-<slug>.md`) for any non-obvious decision.
  Template: Context / Decision / Consequences.
- **Update the index**: one line in `MEMORY.md`. Pointers only — never full content.
- **Dedup before write**: search first; update rather than duplicate.
- **Never store** what code or git already records.
- **Reference, don't copy**: link to a file instead of pasting its content.
