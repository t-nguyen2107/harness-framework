# Rule — Code Style

- Files ≤ ~300 lines. If longer, split and note why.
- Comment the *why*, not the *what*. No trivial comments.
- Functions: single responsibility; ≤ ~40 lines preferred.
- Naming: follow the host language's prevailing convention.
- Imports: stdlib → third-party → local; grouped and sorted.
- No dead code, no commented-out blocks. Delete it; version control remembers.
